# 🕎 ניו יורק · חנוכה תשפ״ז

אפליקציית ווב (PWA) משפחתית לטיול: תוכנית יומית, ניווט ב־Waze, מסמכי נסיעה, הוצאות, רשימת הכנות ונרות חנוכה.

## איך זה בנוי
- **הקוד** — בריפו הזה, מוגש דרך GitHub Pages. אין בו נתונים אישיים.
- **הנתונים** (התוכנית, ההוצאות, המסמכים, מספרי ההזמנה) — ב־Firebase Firestore, מאחורי התחברות עם גוגל.
  רק בעל הטיול וחשבונות שהוא הוסיף (עוד ← שיתוף והרשאות) יכולים לקרוא ולכתוב. כל שינוי מופיע מיד אצל כולם.
- עובד גם בלי קליטה: מה שנטען פעם אחת נשמר במכשיר, ושינויים נשלחים כשהחיבור חוזר.

## הוספת בן משפחה
עוד ← שיתוף והרשאות ← ״הוספה״ ← כתובת ה־Gmail שלו. שולחים לו את הקישור לאתר, הוא נכנס עם גוגל ו״מוסיף למסך הבית״.

## קבצים
```
index.html            מעטפת
styles.css            עיצוב
app.js                ממשק ולוגיקה
cloud.js              התחברות וסנכרון מול Firebase
firebase-config.js    מזהה הפרויקט ב־Firebase (לא סוד)
sw.js                 עבודה בלי קליטה (אחרי עדכון קוד: להעלות את מספר הגרסה)
manifest.webmanifest  התקנה כאפליקציה
icons/                אייקונים
```
